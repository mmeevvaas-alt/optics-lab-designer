
# Optics Lab Designer — סימולטור עדשות למעבדה

אפליקציית Streamlit אינטראקטיבית לתכנון והדגמת ניסוי העדשות.

## מה יש באפליקציה

### חלק 1 — עדשה יחידה
- בחירת עדשה מתוך מלאי המעבדה.
- חישוב מיקום דמות והגדלה.
- שרטוט קרניים.
- גרף לינארי של `1/v` מול `1/u` או להפך.
- סימולציית מדידות עם רעש ו-fit לינארי.
- הצגת גבול גודל עצם לפי גודל המסך.
- הצגת EFL, BFL, עובי, clear aperture וקוטר.

### חלק 2 — שתי עדשות
- בחירת הגדלה רצויה וכיוון הדמות.
- בחירת tolerance.
- אילוצי מסילה, מרחקים ורזולוציית מיקום.
- חיפוש אוטומטי של מאות מערכות אפשריות מתוך עדשות המעבדה.
- בחירת פתרון והצגת:
  - מיקום העצם;
  - L1 ו-L2;
  - דמות ביניים;
  - מסך;
  - הגדלה בכל שלב;
  - אורך המערכת;
  - הערכת vignetting וגובה עצם מלא.
- sensitivity analysis להזזת L2.

### השוואה לניסוי
מאפשר להזין מרחקים וגודל דמות שנמדדו בפועל ולהשוות לתחזית המודל.

## ניסוי התאבכות ועקיפה

בוחרים "התאבכות ועקיפה" בראש העמוד. כל הפרמטרים (a, d, L, λ, צפיפות השריג) מוזנים ידנית.

- **שני סדקים (יאנג):** תמונת מסך מדומה, גרף עוצמה עם מעטפת הסדק היחיד, Δx, מספר הפסים בתוך המעטפת, סדרים חסרים, ו-D צפוי על פני N פסים.
- **סדק יחיד:** מיקומי פסי החושך yₙ ו-Dₙ = 2yₙ, רוחב הפס המרכזי.
- **שריג:** מיקומי הסדרים בחישוב מדויק, שגיאת קירוב הזווית הקטנה, והשפעת הטיית השריג.
- **שערה:** תבנית העקיפה לפי עיקרון בבינה וחישוב Dₙ צפוי.
- **בדיקת תוצאות מדוח:** מזינים את מדידות הסטודנטים ומקבלים את λ (או d, או עובי השערה), סטייה מ-632.8 nm, אי-ודאות, וזיהוי טעויות נפוצות (אי-חלוקה ב-2, N במקום N−1, שגיאה שיטתית ב-L).

המודל: עקיפת פראונהופר עם חישוב זווית מדויק sinθ = x/√(x² + L²).

## הנחת המודל

החישובים משתמשים במודל **עדשה דקה ואופטיקה פראקסיאלית**, כאשר `EFL` משמש כאורך המוקד.
BFL ועובי העדשה מוצגים אך אינם מספיקים לבדם לקביעת שני המישורים הראשיים של עדשה עבה.

זו בחירה מכוונת: האפליקציה מיועדת לתכנון מוקדם וליצירת prediction, שאותו הסטודנטים צריכים לבדוק במעבדה.

## התקנה

ב-Windows:

1. התקיני Python 3.11 ומעלה.
2. פתחי Terminal בתיקייה.
3. הריצי:

```bash
pip install -r requirements.txt
streamlit run app.py
```

או לאחר התקנת החבילות לחצי פעמיים על:

`run_app.bat`

## קבצים

- `app.py` — האפליקציה (ניסוי העדשות ובורר הניסויים).
- `interference.py` — ניסוי ההתאבכות והעקיפה.
- `requirements.txt` — החבילות הדרושות.
- `run_app.bat` — הפעלה נוחה ב-Windows.

- `lenses.csv` — טבלת העדשות שסיפקת, לשימוש/עדכון עתידי.
